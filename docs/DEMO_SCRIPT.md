# Wysend demo script

Length: 2:45. Record in English on desktop Chrome with the extension loaded. Use the sample desk (`npm run demo`) so the video does not depend on another product’s interface. No third-party logos.

On screen the name is **Wysend**. Say it WHY-send once.

| Time | Shot | Voiceover |
|---|---|---|
| 0:00–0:08 | Side panel title and the sample complaint, full frame. | “This is Wysend. WHY-send. What you see is what you send.” |
| 0:08–0:18 | Slow pan across the complaint: name, phone, account number, key. | “Support leads, founders, and engineers paste this kind of text into AI tools every day. The reply is useful. The raw text should not leave the machine.” |
| 0:18–0:28 | Cut to the four step badges. Finger on step 1, Detect. | “Gemini Nano, through Firebase AI Logic, reads the original only on this device. The cloud model later sees one approved payload, and nothing else.” |
| 0:28–0:38 | Airplane mode, or the network icon off. Paste or select the complaint again. Badge stays Rules or On-device. | “Turn the network off. Detection still runs. Raw text has no cloud fallback.” |
| 0:38–0:48 | Network back on. Select the complaint. Right-click: Wysend, finish this privately. | “Select the text. Wysend opens on the selection.” |
| 0:48–1:05 | Side panel, before and after. Highlight a placeholder. | “Names, the phone number, the account, and the key are placeholders. The same value keeps the same placeholder.” |
| 1:05–1:15 | If Nano is downloading, hold on the progress bar. If it is ready, click Refine with Nano and show the On-device badge. | “When Nano is on the machine, a second pass looks for anything the rules missed. The badge says On-device. That signal comes from the SDK.” |
| 1:15–1:32 | Scroll to Outbound payload. Point at the byte count, then at a placeholder in the text. | “This is the exact string that will leave. Byte count on the right. The phone number is not in it. The key is not in it.” |
| 1:32–1:40 | Click Approve payload. | “I approve this payload. That is the only text the cloud call is allowed to use.” |
| 1:40–1:55 | Draft reply is selected. Click Run task. Hold until the result appears. Point at the Task badge: In cloud. | “Draft a reply. The task badge says In cloud. Again, that is the SDK’s inference source, not a label we invented.” |
| 1:55–2:10 | Toggle Show restored values. The name and phone appear in the result only. | “Restoration happens here, after the call. The cloud reply still has placeholders. This panel fills them back in.” |
| 2:10–2:22 | Click Copy. Paste into the sample desk reply box. The thread shows the restored reply. | “I read it, then I copy it. Nothing was inserted into the page until I did that.” |
| 2:22–2:35 | Briefly open Paste protection, then return to the four steps. | “Paste protection is there if you want it. The product is the task: detect, approve, send what you saw, restore locally.” |
| 2:35–2:45 | End card: Wysend, and the tagline under it. | “The cloud never sees your secrets. You see exactly what it sees.” |
